# Improve output

Use after a technically valid HTML file that still feels like an AI draft.

## Goals

- Sharper first screen (promise + four scores)
- Parking and return time visible without taps
- Venice comparison readable in 30 seconds
- Prose like a travel editor: concrete nouns, clock times, named lots
- Visual rhythm: hero → rank → cards → deep chapters → practical
- Dark mode contrast
- Print: no wasted ink, no hidden accordions

## Edits allowed

- CSS spacing, type scale, color tokens
- Component copy
- SVG illustration
- JS polish (filters, persist)
- Adding missing required fields into existing sections

## Edits forbidden

- New destinations
- Changing scores without regenerating `scored_destinations.json`
- CDNs, libraries, webfonts
- Breaking `file://`

## Pass/fail vibe check

If a parent would still open Google Maps “just to be sure where to park,” the parking block is not good enough. Improve it.
